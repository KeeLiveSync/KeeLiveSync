# Security policy

English · [Deutsch](#deutsch)

## Reporting a vulnerability

Please do not report security problems in public issues.

Use GitHub's private reporting instead: open the [Security tab](https://github.com/KeeLiveSync/KeeLiveSync/security) and choose **Report a vulnerability**. Only you and the maintainers can see the report.

If you have no GitHub account, write to KeeLiveSync@gmail.com. E-mail is not encrypted, so please describe the problem only briefly at first; we will agree on a safe way to share the details.

Helpful details are the affected version, the KeePass version, the steps to reproduce and what an attacker could achieve.

KeeLiveSync is maintained in spare time, so there is no guaranteed response time. We will answer as soon as we can and tell you when a fix is released.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope are the KeeLiveSync plugin, its Microsoft sign-in and token storage, the synchronization with OneDrive and the signed release and update information.

An attacker who already runs code under your Windows account can also read keystrokes and data protected for that account, including the stored sign-in token. KeeLiveSync cannot fully protect against that, but reports that make such an attack easier are welcome.

# Sicherheitsrichtlinie

## Sicherheitslücke melden

Bitte melde Sicherheitsprobleme nicht in öffentlichen Issues.

Nutze stattdessen die private Meldefunktion von GitHub: Öffne den [Reiter Security](https://github.com/KeeLiveSync/KeeLiveSync/security) und wähle **Report a vulnerability**. Die Meldung sehen nur du und die Maintainer.

Ohne GitHub-Konto schreib an KeeLiveSync@gmail.com. E-Mails sind nicht verschlüsselt, beschreibe das Problem daher zunächst nur knapp; wir vereinbaren dann einen sicheren Weg für die Details.

Hilfreich sind die betroffene Version, die KeePass-Version, die Schritte zum Nachstellen und was ein Angreifer damit erreichen könnte.

KeeLiveSync wird in der Freizeit gepflegt, eine feste Antwortzeit gibt es deshalb nicht. Wir antworten so bald wie möglich und sagen dir, wenn eine Korrektur veröffentlicht ist.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste Version.

## Geltungsbereich

Dazu gehören das KeeLiveSync-Plugin, die Microsoft-Anmeldung und die Speicherung des Tokens, der Abgleich mit OneDrive sowie die signierten Releases und Update-Informationen.

Wer bereits Code unter deinem Windows-Konto ausführt, kann auch Tastatureingaben und für dieses Konto geschützte Daten lesen, darunter das gespeicherte Anmelde-Token. Davor kann KeeLiveSync nicht vollständig schützen, Meldungen, die einen solchen Angriff erleichtern, sind aber willkommen.
